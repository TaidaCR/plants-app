# 🌿 Adansonii - Plant Care App
Aplicación web de gestión para el cuidado y seguimiento de plantas.
Permite registrar plantas, programar riegos, fertilizaciones y tratamientos,
e identificar especies mediante fotografía.

## 🛠️ Stack Tecnológico

### Frontend
- React 19 + Vite 8
- Tailwind CSS v4
- Zustand (state management)
- React Router v7
- Firebase Auth (Google OAuth)

### Backend
- Express 5
- MongoDB Atlas (Mongoose 9)
- Cloudinary (almacenamiento de imágenes)
- PlantNet API (identificación de plantas)

## 🚀 Características
- Login con Google (Firebase Authentication)
- CRUD completo de plantas
- Subida de imágenes con optimización automática
- Identificación de especies por foto (PlantNet API)
- Registro de riegos, fertilizaciones y tratamientos
- Panel de cuidados con recordatorios
